pubcheck.hold#

A held post becomes a desk item: an issue in a private repo, labelled for the desk.

When an unattended writer’s text is held (flagged, or the check unavailable), nothing is lost and nothing is refused silently: file_hold() opens one issue in the hold repo (setting hold_repo, by default the desk’s own private repo) with the label the desk reads (hold_label, by default escalate), carrying the target, the title, the text and the categories, so the owner can publish it as is, edit it, or drop it.

The hold repo receives the text, so it must be private: file_hold() asks GitHub (never a cache) just before filing, and files nothing when it is public or unknown, or when no hold_repo is configured. Credential-shaped strings are redacted from the copy (redact()). The same text held twice (a retry) is filed once: the body carries the text’s hash, and an open issue with that hash is reused.

>>> redact("token: ghp_" + "A1" * 18)
'token: [credential redacted: github_token]'
