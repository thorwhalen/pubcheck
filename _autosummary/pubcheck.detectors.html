pubcheck.detectors#

The detectors: what in a text a public reader may not see.

A detector is a callable (text, ctx) -> [(category, term)]. ctx carries what the check knows about the post: repo (the target), surface (git commit, gh issue create, correspond send…), terms (the registry’s terms for that repo) and private_slugs (repos known to be private). Whitespace is normalised before any detector runs, so a name wrapped across lines still matches. term is what a local author needs to reword the text; it never leaves the machine (the CLI prints it only with --terms, and the log never holds it). A credential’s term is its pattern name, never the secret.

  • registry: a term of an acquaint record a public reader may not see;

  • owner-relation: “the operator stated”, “the owner’s preference”, “my agents”… (text inside double quotes, curly quotes or backticks is skipped: a quoted phrase is an example, not a claim);

  • private-ref: a repo known to be private, a private companion (<private_owner>/_<name>), this machine’s home folder, and the operator’s private_patterns (ctx["private_patterns"], from the settings);

  • session-link: claude.ai/code/session_… (not on commits, whose session links a commit hook strips);

  • credential: a credential-shaped string (openloops.egress.find_credentials()), and, when the operator sets credential_scanner, what that external scanner finds (scanner_credential());

  • mention: an @login or @org/team outside code, which notifies a person: sending it is messaging them. Only in UNATTENDED_DETECTORS, since an attended author chose to notify.

>>> findings(["As the owner asked, we fixed it"], {})
[('owner-relation', 'the owner asked')]
>>> findings(["ping @octocat about it"], {}, detectors=UNATTENDED_DETECTORS)
[('mention', '@octocat')]
>>> findings(["write to me@example.org or see `@octocat`"], {}, detectors=UNATTENDED_DETECTORS)
[]

pubcheck.detectors.scanner_credential(text, ctx)[source]#

What an external secret scanner finds, named <scanner>:<rule id>.

Off unless the operator sets credential_scanner (betterleaks is the one weighed in thorwhalen/pubcheck#3; any gitleaks-compatible stdin command works, with credential_scanner_args for another argument list). It adds the long tail of vendor formats to the built-in credential(), which stays.

It runs once per check, over every text of the post together (whole_batch). The text goes on stdin, never in argv; the report is redacted; validation is never asked for; the scanner runs from a neutral folder, so a repo’s own scanner config is not read, and only from an absolute path outside the current folder.

A scanner that is missing, fails or runs out of time is a gap, logged every time. An attended check carries on with the built-in patterns (and says so once on stderr); an unattended one raises ScannerUnavailable, so the check is unavailable and the text is held, as any other lookup that cannot be made.

>>> scanner_credential("AKIA...", {})  # no scanner configured
[]
