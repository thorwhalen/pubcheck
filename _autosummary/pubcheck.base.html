pubcheck.base#

What every part of the check shares: the time budget, private files, the settings and the event log.

The budget. Every lookup (gh, acquaint, git) runs inside one Budget, so a check decides within its deadline instead of being killed by its caller. Out of time, a lookup answers None (unknown), and the caller decides what unknown means: presumed public for visibility, unavailable for the registry.

Settings. One mapping, read from ~/.config/pubcheck/config.toml ($PUBCHECK_CONFIG names another file), with environment variables over it, and keyword arguments over both at each call site. The keys are in DFLT_SETTINGS.

The log. ~/.local/state/public-text-guard/events.jsonl (mode 0600, $PUBLIC_TEXT_GUARD_STATE_DIR), one JSON object per decision worth keeping: never the text and never the matched terms, only the categories, the repo, the writer, a short hash of the text (so two events about the same text can be paired), an error’s type, and an override’s reason as its author wrote it.

>>> b = Budget(0)
>>> b.run(["true"]) is None  # no time left: no subprocess at all
True

pubcheck.base.DFLT_SETTINGS = {'budget_seconds': 12.0, 'hold_label': 'escalate', 'hold_repo': None, 'private_issues': None, 'private_owner': None, 'private_patterns': ()}#

The settings and their defaults. Everything that names the operator’s own repos or folders is unset by default and lives in their config file, never in this code:

  • hold_repo: the private repo where a held post becomes a desk item (unset: no item is filed; it must be private, or nothing is copied there);

  • hold_label: the label the desk reads;

  • private_owner: the account whose <owner>/_<name> repos are private companions (a reference to one is private, and a flag points at the target’s companion);

  • private_issues: the private repo for context that has no companion;

  • private_patterns: more regexes for private references (working folders, the layout of the operator’s machines), on top of this machine’s home folder.
